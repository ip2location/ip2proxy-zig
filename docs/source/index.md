# IP2Proxy Zig

Enables the user to detect proxy servers, VPNs, Tor exit nodes, web proxies, public proxies, residential proxies, consumer privacy networks, enterprise private networks, data centers, search engine robots and AI crawlers, and to find the country, region, city, ISP, domain, usage type, ASN, last seen, threat, provider and fraud score associated with any IPv4 or IPv6 address.
